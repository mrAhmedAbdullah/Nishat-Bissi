\# Bissi - Community Interest-Free Deposit Tracking Platform



\## Tech Stack

\- Backend: Java 17, Spring Boot 3.x, Spring Security (JWT), Spring Data JPA

\- Frontend: React.js

\- Database: PostgreSQL

\- Config: Spring Cloud Config Server

\- DevOps: Docker, Kubernetes, Oracle Cloud Infrastructure (OCI)



\## Modules

\- User Registration \& Diary Approval Workflow

\- Deposit \& Withdrawal Management (Ledger)

\- Audit Logs

See `docs/architecture.md`
